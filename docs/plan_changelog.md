## 2026-08-02 — compartment-wide exact-run decision

The reference-only freeze emitted 51 sets and 9,468 memberships. The exact
primary run enumerated all 63,504 balanced within-plex assignments on 8,021
qualified phosphosite features and 3,524 fixed-null-eligible parent genes.

- Podocyte all-enriched: 89 observable genes, statistic 0.783, conditional
  exact p=0.000819, two-sided max-|T| FWER=0.324.
- Mesenchymal/stromal all-enriched: 40 genes, statistic 0.577, conditional
  p=0.0128, FWER=0.703.
- TAL all-enriched: 16 genes, statistic 0.587, conditional p=0.0463,
  FWER=0.683.
- DCT2/CNT context: four observable genes, non-evaluable at the frozen minimum
  of eight.

Four tier/score rows passed their score-specific two-sided 51-set family, but
no compartment passed the complete adversarial gate. Podocyte passed the seven-covariate
annotation null (BH q=0.0455) but failed the primary family gate. The
mesenchymal/stromal high-specificity tier passed for the median score
(FWER=0.0348) yet lacked scale, matched-observability, and contributor-
concentration robustness: the uncentered statistic attenuated to
0.057 and the parent-protein-adjusted statistic reversed to -0.171. No primary
all-enriched compartment row was family-significant.

Protein and phosphosite reporter-position diagnostics showed no significant
within-block linear trend. This does not remove the step-shaped block alias;
condition remains non-identifiable from tag block. The stop rule retires
further compartment mining.

## 2026-07-29 — computation-only exact-run amendment

The first exact run was interrupted during label-blind site preparation,
before any exact permutation result was produced or inspected. Profiling showed
that the de-duplication function was performing thousands of one-row pandas
reductions even when every canonical phosphoform key was already unique.

Two computation-only changes were made:

1. An exact fast path now returns already-unique canonical keys without
   one-row reductions. The general duplicate-key path and its per-sample median
   rule are unchanged.
2. The permutation batch size was increased from 256 to 1,024 assignments.

Neither change alters the site universe, assignment space, parent-gene score,
null distribution, set statistic, multiplicity correction, or claim gates.
Smoke-output equivalence is checked before the exact run is restarted.

## 2026-07-29 — pre-interpretation audit corrections

An independent code and estimand audit was completed while the first full
exact run was executing. That run completed and is retained as an audit
baseline, but it is not the definitive claim-decision run because the audit
identified omissions in the implementation of already planned sensitivities
and gates. The corrections below were specified before interpreting that
baseline as a manuscript result:

1. The normalization gate now requires positive, concordant direction under
   both the official-scaled uncentered profile and the summed
   signal-to-noise, channel-centered profile.
2. Leave-one-gene-out direction is accepted only when one result exists for
   every observable set member.
3. The old ratio-or-breadth atlas flag is renamed
   `non_distal_specific_or_broad` and retained as a diagnostic/reference-set
   construction filter. The manuscript claim gate now uses the narrower
   `broadly_expressed` flag: target expression plus detection in at least four
   unrelated compartments.
4. A deduplicated multi-modified/composite phosphoform sensitivity is
   implemented. Composite localization strings are evaluated by their minimum
   component score.
5. The configured strict manual-anchor removal is checked against the Stage-0
   phosphoform table. Because Stage 0 identifies zero isolated qualified
   anchors, this is an explicit no-op; the code fails closed if a future
   qualified anchor lies outside the strict parent-gene exclusions.
6. Statistical eligibility is separated from publication promotion. Perfect
   condition-to-reporter-tag-block aliasing and the absence of an isolated
   canonical NCC/SPAK phosphoform prevent a promoted mechanistic title even if
   a gene-set statistic were to pass.
7. The claim decision now distinguishes DCT2/CNT non-evaluability from ASDN
   failure. If DCT2/CNT is under-covered and ASDN fails, the output says that
   no beyond-axis claim is supported while preserving the fact that DCT2/CNT
   was not tested with adequate coverage.
8. The secondary observability-matched annotation null is restricted to the
   primary profile, primary parent-gene score, primary canonical exclusion,
   and the two frozen primary sets. This changes computation only; it avoids
   thousands of unplanned profile-by-score-by-comparator diagnostics.

The frozen gene-set membership file remains byte-identical
(`ed64f0e20361d21ebc4d2483fce383f5f82e94bb7ec43b66156826c8eb86b945`).
The primary site filter, parent-gene score, exact 63,504-assignment null,
set statistic, minimum observable-gene threshold, and multiplicity rules are
unchanged.

## 2026-07-29 — Grey60 adversarial no-go decision

The owner-authorized Grey60 audit completed under
`config/grey60_adversarial_reanalysis.yaml`.

- Gate A passed: the frozen 48-gene score retained selection-adjusted
  OSD-771 ISS-terminal evidence.
- Gate B failed: zero of 27 flight-blind WGCNA specifications recovered a
  compact Grey60 module. The primary reconstruction overlapped 12 genes in a
  511-gene module (Jaccard 0.0219) and projected with p=0.831.
- Gate C passed: all gene and mouse influence checks retained direction.
- Gate D failed narrowly because the baseline BSL-versus-VIV Hedges g was
  0.563, above the frozen 0.50 ceiling, although technical/composition
  adjustment retained 89.0% of the main effect.
- Gate E failed: only two of four terminal-study effects were positive and the
  modified Hartung-Knapp meta-estimate was g=0.163 (95% CI -0.658 to 0.984).
- Gate F passed as an internal specificity sensitivity but could not establish
  kidney specificity.

The final decision is `NO_GO_RETIRE_STANDALONE_GREY60`. The branch may be used
only as exploratory context or a technical case study. The recommended next
locked project is the OSD-462 matched-library robustness analysis, followed
only if warranted by a cross-mission control-choice sensitivity analysis.

Post-run code audit corrections were conservative: OSD-462 technical-replicate
suffix parsing, a fixed OSD-253 score reference, modified Hartung-Knapp
uncertainty, and explicit signature-coverage/sample-count assertions. None
changed the decision.
